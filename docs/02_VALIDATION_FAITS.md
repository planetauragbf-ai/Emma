## 3. Conséquence éditoriale (décision à appliquer partout)

Architecture de preuve du problème, dans cet ordre :
1. **France, salariés** : Malakoff Humanis 2025 (18 % en difficulté, impact pro).
2. **France, grand public** : 12,82/20 · 56 % connaissances de base · 24 % à découvert · dépression ×3.
3. **France, gisement** : 200 Md€ d'épargne salariale + 7,9 Md€ en déshérence → le Cockpit a un sous-jacent réel.
4. **US, marché précurseur** : PwC 59 % (2026) — présenté comme preuve de la catégorie, pas comme douleur France.

Le « 3 h/semaine » sort de l'argumentaire principal (trop fragile une fois
reformulé honnêtement) ; il peut rester en note de bas de page au mieux.
